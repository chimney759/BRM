# 业务需求管理系统

独立业务需求管理系统，不依赖、也不会读写原有后台项目。当前默认通过本地 Node.js API 访问 SQLite，需求、用户、项目、版本与不可变的流转历史都会写入真实数据库文件，而不只是静态页面或浏览器缓存。

## 工程基线

本仓库按可生产部署的系统维护，而非静态样式页。业务领域、服务端权威边界、禁止的前端补丁模式、数据与安全规则，以及功能变更和验收门槛，以 [ENGINEERING-GUARDRAILS.md](./ENGINEERING-GUARDRAILS.md) 为强制标准。所有涉及业务行为、权限、流程或数据模型的迭代，均须遵守该文档，并同步维护 API 契约、数据库迁移和自动化测试。

## 本地演示

在本目录启动一个 Node.js 服务：

```sh
npm start
```

访问 [http://127.0.0.1:3000/](http://127.0.0.1:3000/)。同一进程会托管前端静态资源和 `/api` REST 服务，避免本地跨端口部署与生产环境不一致。开发期间也可继续把静态资源放入 Nginx、CDN 或独立前端服务，但生产推荐前端将 API 配置为同域 `/api`。

- 服务默认仅监听 `127.0.0.1:3000`，不会暴露给局域网；可通过 `BRMS_HOST`、`BRMS_API_PORT` 调整监听地址与端口。
- SQLite 文件为 `data/brms.sqlite`，已被 `.gitignore` 忽略，不会提交到代码仓库。
- 健康检查：`http://127.0.0.1:3000/api/health`；自动化接口测试：`npm test`。
- 初始数据包含五个业务项目及演示需求；数据库首次启动时自动创建。

默认服务不信任浏览器传入的演示身份请求头，页面也不会开放角色切换。本机验收多角色流程时，使用 `npm run start:demo` 启动 API；该开发命令会启用 API 进程的 `BRMS_DEMO_AUTH=1`，而当前本地 `config.js` 已启用 `localAuth: true` 以允许浏览器发送演示身份。前者只允许浏览器发送演示身份，后者才允许服务端解析该身份；缺少任一开关均不会切换身份。生产、预发布和共享环境必须保持两者关闭，并由企业 SSO 或真实登录会话提供身份。

## 端口约束

建议本地演示固定使用 `127.0.0.1:3000` 托管应用与 API。未来接入 PostgreSQL 时，数据库默认 `127.0.0.1:5432`，不要直接暴露到公网；云端只由 API 服务访问数据库。SQLite 文件位置可以通过 `BRMS_DB_PATH` 指定，方便备份、测试和后续数据迁移。

## 数据与云端迁移

本地 SQLite 是零依赖的演示存储适配器。正式部署时建议替换为 PostgreSQL 16，并保留前端到 `/api` 的接口边界；因此浏览器端无需持有数据库账户、连接串、密钥或访问令牌。云端对接规范见 [API-CONTRACT.md](./API-CONTRACT.md)，部署、数据一致性和迁移方案见 [DEPLOYMENT-DESIGN.md](./DEPLOYMENT-DESIGN.md)，工程约束见 [ENGINEERING-GUARDRAILS.md](./ENGINEERING-GUARDRAILS.md)。

## 云端部署切换

部署时将 [config.example.js](./config.example.js) 作为模板创建 `config.js`，填写 API 域名并在 `data-access.js` 之前加载它。系统只提供 HTTP 仓储，需求、项目、用户、项目版本、工作台待办、需求归档和状态动作统一经由 API 访问；项目版本看板的字段展示偏好仅保存在浏览器本地，不包含业务数据。浏览器配置中不得放置数据库连接、服务端密钥或访问令牌。
# 部署与首次登录

服务首次连接到空数据库时，会自动创建以下账户：

- `Admin`：系统管理员，部门为“系统管理”。

首次启动前必须在服务器环境中设置一次性初始密码。密码不会写入代码或前端文件：

```sh
export BRMS_ADMIN_PASSWORD='请设置Admin的登录密码'
npm start
```

若空数据库启动时未设置该环境变量，服务会拒绝启动并提示补齐配置。`Admin` 首次登录后必须立即设置新密码；改密前只能查看账户身份、修改密码或退出，无法进入或操作业务系统。账户已创建后，后续重启不会读取该环境变量，也不会覆盖用户自行修改过的密码。

若使用 `npm run deploy:provision-accounts` 重新生成初始管理员，系统会重置其登录密码并再次要求首次登录改密。请仅在部署初始化或应急重置时执行该命令。
